# Contributing to MedHarbor

Thank you for your interest in MedHarbor. The project is in an early stage and run by its founder, so small, focused help is the most useful.

## Where to write

| Repository | What it is for | How to get in touch |
| --- | --- | --- |
| [responsible-ai](https://github.com/medharborai/responsible-ai) | How the AI is designed and the rules we follow | Open an issue with questions or suggestions |
| [medharborai-website](https://github.com/medharborai/medharborai-website) | The website medharborai.com | Open an issue for broken links, typos or translation mistakes |
| [brand-assets](https://github.com/medharborai/brand-assets) | Official logos, colours and images | Issues are closed: email [info@medharborai.com](mailto:info@medharborai.com) |
| [.github](https://github.com/medharborai/.github) | Organisation profile and community files | Issues are closed: email [info@medharborai.com](mailto:info@medharborai.com) |

Funders and partners can write to [partnerships@medharborai.com](mailto:partnerships@medharborai.com).

## Issues

- Search existing issues first.
- One topic per issue, with a clear title.
- For a website problem, say which page, which language and which browser.
- Never include real personal or medical data. Use made-up examples.
- Security problems never go in issues: see [SECURITY.md](SECURITY.md).

## Pull requests

Small pull requests are welcome: typo fixes, broken links, translation improvements and accessibility fixes. For anything bigger, open an issue first so we can agree on the approach.

## Code of conduct

By taking part you agree to follow our [Code of conduct](CODE_OF_CONDUCT.md).
