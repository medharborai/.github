# Security policy

MedHarbor is in development. There is no live product yet. The public code we publish today is the website [medharborai.com](https://medharborai.com) and supporting documents.

## Reporting a vulnerability

If you find a security issue in any MedHarbor repository or on medharborai.com:

1. Email **[info@medharborai.com](mailto:info@medharborai.com)** with the subject **Security**.
2. Describe the issue, where you found it and, if possible, the steps to reproduce it.
3. Please do **not** open a public issue, pull request or discussion about it, and do not share it publicly until we have fixed it.

Never include real personal or medical data in your report. Use made-up examples.

## What happens next

- We will confirm that we received your report.
- We will look into it, keep you informed and tell you when it is fixed.
- If you wish, we will credit you once the fix is public.

Thank you for helping keep MedHarbor and its future users safe.
